# Склады и товары — Django REST Framework

Реализация учебной задачи CRUD для продуктов и складов.

## Возможности
- CRUD продуктов и складов.
- Связь складов с продуктами через промежуточную модель `StockProduct`.
- У каждого продукта на каждом складе своя стоимость хранения (`price`).
- Создание и обновление состава склада через вложенное поле `products`.
- Поиск продуктов по названию и описанию: `/products/?search=помид`.
- Поиск складов по ID продукта: `/stocks/?products=1`.
- Дополнительный поиск складов по названию/описанию продукта: `/stocks/?search=помид`.
- Пагинация списков (по умолчанию 10 объектов).

## Запуск на Windows (PyCharm)
1. Откройте эту папку в PyCharm.
2. В терминале PyCharm выполните:
   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   py manage.py migrate
   py manage.py runserver
   ```
3. Откройте `http://127.0.0.1:8000/api/`.

SQLite используется по умолчанию, поэтому отдельная установка PostgreSQL не требуется.

## API
Базовый адрес: `http://127.0.0.1:8000`

### Продукты
- `GET /products/` — список.
- `POST /products/` — создать.
- `GET /products/{id}/` — получить.
- `PUT/PATCH /products/{id}/` — изменить.
- `DELETE /products/{id}/` — удалить.
- `GET /products/?search=помид` — поиск по имени и описанию.

Пример POST:
```json
{"name": "Помидоры", "description": "Свежие красные томаты"}
```

### Склады
- `GET /stocks/` — список.
- `POST /stocks/` — создать склад.
- `GET /stocks/{id}/` — получить.
- `PUT/PATCH /stocks/{id}/` — изменить.
- `DELETE /stocks/{id}/` — удалить.
- `GET /stocks/?products=1` — склады, содержащие продукт с ID 1.
- `GET /stocks/?search=помид` — дополнительный поиск по названию/описанию продукта.

Пример POST/PUT склада:
```json
{
  "address": "Москва, ул. Примерная, 10",
  "products": [
    {"id": 1, "price": "15.50"},
    {"id": 2, "price": "8.00"}
  ]
}
```
`id` — существующий ID продукта. `price` — стоимость хранения этого продукта на данном складе.
При обновлении переданный список `products` становится актуальным составом склада: отсутствующие в списке связи удаляются, существующие обновляются, новые создаются.

### Проверка
В браузере откройте `/api/` или `/products/`. Для POST/PATCH/DELETE используйте DRF Browsable API, Postman или REST Client.
